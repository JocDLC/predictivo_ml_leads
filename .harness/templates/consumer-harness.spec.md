# Consumer harness verification

## Purpose

Provide executable checks for projects generated by the profile composer.
This specification covers the harness, not the future product's behavior.

## Requirements

### Requirement: Required resources are executable and present

The consumer SHALL contain its declared profile resources and an executable smoke
suite with at least one successful case. Missing or empty required suites SHALL
produce a nonzero test exit code.

#### Scenario: A generated project verifies its harness

- **WHEN** test is executed from a generated consumer
- **THEN** its own smoke checks context and required resources successfully

#### Scenario: A required smoke is missing

- **WHEN** the required smoke file is removed
- **THEN** test fails with a nonzero exit code

### Requirement: Optional checks follow active profiles

The consumer SHALL use its explicit context to select optional checks and SHALL
NOT invoke tools from inactive profiles.

#### Scenario: Base has no OpenSpec dependency

- **WHEN** build is executed with only the base profile active
- **THEN** parser checks run and OpenSpec is explicitly skipped
