Enter explore mode (Fase 1). Investigate the codebase, clarify requirements, evaluate alternatives and risks without implementing code changes.

1. Check active changes with `openspec list --json`.
2. Explore the codebase and consult `graphify-out/GRAPH_REPORT.md` when available.
3. Visualize options and trade-offs with diagrams or tables.
4. Confirm unresolved scope decisions before `/opsx:propose`; reuse valid approvals for the same scope. This workflow belongs to the SDD route, not every small change.
